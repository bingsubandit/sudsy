# Kit index

Generated by `cargo xtask codegen` from the `//! concept:` headers of the modules of the shared and language crates (see [adding-a-language.md](../architecture/adding-a-language.md)); do not edit.
One row per concept (one behavior). `turned on by`: the data the shared module reads (`option:` a `lang.yaml` option, `tag:` a grammar tag, `rules:` a `format.rules` section, `grammar:` a grammar line type, `rule:` and `family:` lint rules): the data a language sets to use it, with no switch of its own. `used by`: languages whose grammar, `format.rules` or `lang.yaml` set the data the shared module reads, or whose code names the module. SINGLE-USE: fewer than two users (a shared module that reads no data may stand alone, see single-use.txt). LOCAL: language modules that carry the concept without using the shared mechanism.
