# Parity queue

Generated by `cargo xtask codegen` from `tests/parity/<tool>/differences.yaml`; do not edit. Per tool: the unclassified count (differing files no `name:N` of `files` explains), the `gap` names by files (`-`: named in a group, not counted), the lint rules by missed findings, each with its `fixes:` note. How to work it: [../development/parity.md](../development/parity.md#the-queue).

## Priority

Weight: the primary tool of a leg 4, a popular secondary 1, any other 0.25. Order: primary legs under the bar come before any secondary leg whatever the score says; the score orders inside each group. Points: to the 85% bar. Needs: the findings (lint) or files (format, the groups of the README table) still to win; causes: the largest until the need is met (a rest no cause names is `unclassified`). Difficulty: per cause 1 when its rule exists and is mapped in the catalog, 3 for a new rule, a format gap or an unclassified rest. Score: weight x points / difficulty. A leg at the bar is not listed.
